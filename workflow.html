Video analysis cron workflow

This archive is generated from markdown analysis artifacts, then built with Hugo and synced to Cloudflare Pages plus the GitHub archive repo when credentials are available.

Current synthesis requirements

  • Actionable Insights are intentionally detailed: future analyses should include 4-7 high-value workflow bullets near the top. When evidence supports elaboration, each bullet should include a few additional sentences with tools, commands or patterns, first step, expected benefit, evaluation criteria, cautions, prerequisites, file names, metrics, rollout sequence, or failure modes.
  • No generic padding or repeated leads: if the video, comments, frames, or external research do not support more detail, the analysis should say so briefly instead of inventing filler. The validator now blocks Actionable Insights bullets that repeat the same bold lead sentence immediately after the bold text.
  • Evidence-backed sections: each full analysis must include core thesis, key insights, timestamped moments, practical workflow, comment insights, deep research, verdicts, screen-level insights, and verification notes.
  • Reviewer gate: before publishing, the workflow requires source/evidence, transcript/comment/frame fidelity, hallucination/overclaim, and Actionable Insights audits.
  • Transcript availability check: the site generator now verifies transcript availability from the actual extracted transcript chunks, so stale unknown metadata cannot hide an existing transcript. Public pages show only a textual status icon: ✅ when transcript chunks are present, ❌ when they are not.
  • Deployment gate: scripts/validate_video_analyses.py blocks deployment if any public analysis is still a draft packet or missing required sections.
